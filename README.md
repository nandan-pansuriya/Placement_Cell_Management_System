# Placement Cell Management System

A web-based **Placement Cell Management System** developed using **Java, Jakarta Servlets, JSP, JDBC, and MySQL** following the **MVC (Model-View-Controller)** architecture. The application simplifies and automates the placement process by providing a centralized platform for students and placement officers.

---

## 📖 Project Overview

The Placement Cell Management System is designed to streamline placement activities within educational institutions. It enables placement officers to manage companies, job postings, and student applications efficiently, while allowing students to explore job opportunities, apply for jobs, and monitor their application status.

The system minimizes manual work, improves data organization, and enhances communication between students and placement officers.

## 🏗️ Architecture

The project follows the **MVC (Model-View-Controller)** architecture.

- **Model** – Java Beans
- **View** – JSP Pages
- **Controller** – Jakarta Servlets
- **Database Layer** – JDBC with MySQL

---

## 🗄️ Database Tables

The application uses the following database tables:

- `users`
- `students`
- `placement_officers`
- `companies`
- `jobs`
- `applications`
